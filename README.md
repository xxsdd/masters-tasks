# 主人的任务

双人任务、提交凭证、验收发积分、自定义奖励、加权抽奖与成就。前端保留用户提供的毛绒表情包。

## Vercel 运行方式

- Next.js 16 / React 19
- PostgreSQL (Neon): 账号、会话、双人空间、任务、积分和操作去重记录
- Vercel Blob 私有存储: 凭证文件，仅在服务端验证空间成员身份后读取
- 使用独立用户名和密码登录，不再依赖 ChatGPT 或 Cloudflare 的用户请求头

## 配置与发布

环境变量（不要提交真实值）：
- `DATABASE_URL`（或 `POSTGRES_URL`）：PostgreSQL 连接地址
- `BLOB_READ_WRITE_TOKEN`：私有 Blob 存储令牌
- `RESEND_API_KEY`、`EMAIL_FROM`：发信服务密钥与经过验证的发信地址；两项都配置后启用邮箱验证和密码找回。参见 [邮箱接入说明](docs/email-setup.md)。
- `EMAIL_CODE_SECRET`（推荐）：独立随机密钥，用于保护验证码哈希；未设置时使用 Resend 密钥。

依次运行：
```
npm ci
npm run db:migrate
npm run build
vercel deploy --prod
```
迁移脚本读取 `.env.local`。数据库结构在 `db/vercel-schema.sql`；应用运行时不会创建表。Vercel 环境变量应连接到实际需要的环境。

## 使用

1. 两个人各自创建账号并保存用户名和密码。
2. 发布者建立双人空间，将同一个网站地址和邀请码发给伙伴。
3. 伙伴登录后输入邀请码加入。
4. 发布任务 → 接受任务 → 提交说明/链接/文件 → 验收或退回修改。
5. 验收后领取积分，用于奖励兑换或抽奖；发布者标记奖励已实际兑现。
6. 页面顶部可以退出登录、切换「我发布 / 我完成」。每个人发布的任务有独立看板和奖励余额，身份切换不会把别人的任务变成自己发布的任务。
7. 发布者可以在任务卡片或详情中删除任务。服务端核对所属看板和发布权限；已结算的积分、历史成就和兑现记录保留。
8. 发信启用后，新账号通过邮件验证码完成注册；旧账号在「双人空间 → 账号与邮箱」验证密码并绑定邮箱。已经验证邮箱的账号登录时需要密码与邮件验证码。
9. 登录页「忘记密码？」使用已验证邮箱重设密码，重设成功会使所有旧会话失效。验证码 10 分钟有效、最多 6 次尝试、一次性使用，并限制发送频率。

手机界面提供底部五栏导航、顶部退出与身份切换、大触控按钮、单列输入表单、数字验证码键盘及安全区域留白。

## 当前边界

- 一个账号加入一个双人空间，暂不支持空间换绑和更换已验证的邮箱。
- 未接通发信服务时，邮箱验证和密码找回显示未启用，用户名密码登录保持可用。已经启用邮箱验证的账号不会因为邮件服务临时停用而绕过验证码。
- 提醒显示在网站内，不会发送邮件或手机推送。
- 凭证支持 JPG/PNG/WebP/PDF，单个文件最大 4MB，最多 3 个/次，30 个/账号/天。
- 连续任务成就按 UTC 提交日期计算；重复任务在上一期通过验收后创建。
- Vercel、Neon、Blob 的免费额度与资源限制以账户控制台为准。

原 Cloudflare 实现保存在首次 Git 提交中；原本地数据仅用于开发验证，并未导入生产数据库。
