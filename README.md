# 主人的任务

双人任务、提交凭证、验收发积分、自定义奖励、加权抽奖与成就。前端保留用户提供的毛绒表情包。

在线使用：[主人的任务](https://masters-tasks.vercel.app/)。支持手机与桌面浏览。

源码：[xxsdd/masters-tasks](https://github.com/xxsdd/masters-tasks) · [MIT 开源许可证](LICENSE)。可自行部署和修改；第三方依赖和图片说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## Vercel 运行方式

- Next.js 16 / React 19
- PostgreSQL (Neon): 账号、会话、双人空间、任务、积分和操作去重记录
- Vercel Blob 私有存储: 凭证文件，仅在服务端验证空间成员身份后读取
- 使用独立账户 ID 和密码登录，不再依赖 ChatGPT 或 Cloudflare 的用户请求头

## 配置与发布

环境变量（不要提交真实值）：
- `DATABASE_URL`（或 `POSTGRES_URL`）：PostgreSQL 连接地址
- `BLOB_READ_WRITE_TOKEN`：私有 Blob 存储令牌

需要 Node.js 24。将 `.env.example` 复制为 `.env.local`，填入自己的数据库连接与 Blob 令牌，再依次运行：
```
npm ci
npm run db:migrate
npm run build
vercel deploy --prod
```
迁移脚本读取 `.env.local`。数据库结构在 `db/vercel-schema.sql`；应用运行时不会创建表。Vercel 环境变量应连接到实际需要的环境。

本地开发运行 `npm run dev`，然后访问终端显示的本地地址。仓库只包含配置模板，不包含真实密钥、用户数据库或凭证上传文件。

## 使用

1. 两个人各自创建账号并保存账户 ID 和密码。
2. 发布者建立双人空间并发布任务，点击「复制任务链接」或手机上的「分享给同伴」。也可在任务卡片点击「分享任务」，或到双人空间复制通用邀请链接。
3. 伙伴打开链接：已登录时自动加入并进入对应任务；未登录时先登录或注册，随后自动继续，无需手动复制邀请码。已配对的双方可以反复使用链接打开任务，其他账号不能加入已经配对的空间。
4. 发布任务 → 接受任务 → 提交说明/链接/文件 → 验收或退回修改。
5. 验收后领取积分，用于奖励兑换或抽奖；发布者标记奖励已实际兑现。
6. 页面顶部可以退出登录、切换「我发布 / 我完成」。每个人发布的任务有独立看板和奖励余额，身份切换不会把别人的任务变成自己发布的任务。
7. 发布者可以在任务卡片或详情中删除任务。服务端核对所属看板和发布权限；已结算的积分、历史成就和兑现记录保留。

手机界面提供底部五栏导航、顶部退出与身份切换、大触控按钮、单列输入表单及安全区域留白。

## 当前边界

- 一个账号加入一个双人空间，暂不支持空间换绑。
- 使用账户 ID 和密码注册登录，不收集邮箱，也不提供自助找回密码。请妥善保存账号信息。
- 提醒显示在网站内，不会发送邮件或手机推送。
- 凭证支持 JPG/PNG/WebP/PDF，单个文件最大 4MB，最多 3 个/次，30 个/账号/天。
- 连续任务成就按 UTC 提交日期计算；重复任务在上一期通过验收后创建。
- Vercel、Neon、Blob 的免费额度与资源限制以账户控制台为准。

原 Cloudflare 实现保存在首次 Git 提交中；原本地数据仅用于开发验证，并未导入生产数据库。

## 邀请链接

- 分享链接使用 `/join#invite=…&board=…&task=…`，邀请令牌放在 URL 片段中，页面访问与来源头不会携带该片段。加入空间通过有登录会话和同源检查的 POST 请求执行。
- 链接会自动选择正确的任务方向，切换身份后也能打开同伴分享的任务。
- 重复打开链接不会重复配对；已有其他空间、无效链接或已被其他人配对时会给出说明。
- 已删除的任务链接会打开任务看板并提示任务不可用。旧版邀请码仍在「我收到邀请 → 使用旧版邀请码」中兼容。
